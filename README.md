# Kovan Nöbeti

Godot 4.7 ile yapılmış üçüncü şahıs hayatta kalma oyunu.

## İndir

[Releases](https://github.com/yusufipk/kovan-nobeti/releases/latest) sayfasından Windows için `KovanNobeti.exe`, Linux için `KovanNobeti.x86_64` dosyasını indir. Linux'ta önce `chmod +x KovanNobeti.x86_64`.

Kaynaktan çalıştırmak için klasörü Godot 4.7 ile aç ve F5'e bas.
